# Custom bookshelf covers

Drop an image here to override a book's Goodreads cover on the shelf (both
the artwork and the spine color it's tinted from).

Name the file after either:

- the book's title, slugified — lowercase, spaces and punctuation → hyphens
  (e.g. "North Woods" → `north-woods.jpg`)
- its Goodreads book id — the numeric id in the review URL
  (e.g. `8703575543.jpg`)

Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
